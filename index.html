Alguns exemplos do que posso construir para seu negócio

Conheça os tipos de projetos que desenvolvo para empresas, marcas e profissionais.

Apollo Engenharia

Site institucional desenvolvido em WordPress para apresentação dos serviços e soluções da empresa. O projeto foi criado com foco em credibilidade, experiência do usuário e geração de contatos comerciais.

Marte Imobiliária

Landing page desenvolvida em WordPress com foco em conversão e captação de clientes. O layout foi estruturado para destacar empreendimentos, fortalecer a presença digital da marca e incentivar o contato dos visitantes.

Formulário DJO BB

Sistema web desenvolvido em PHP para preenchimento de formulários e geração automática de documentos em PDF. O projeto automatiza processos internos e reduz o tempo gasto em tarefas operacionais repetitivas.

Chat Escritório

Ferramenta web criada com HTML, CSS e JavaScript para iniciar conversas no WhatsApp utilizando mensagens pré-definidas. A solução agiliza o atendimento e contribui para a padronização da comunicação com clientes.

LotoGênio

Aplicação full stack desenvolvida com Java, Docker e banco de dados para geração e análise de apostas da Mega-Sena e Lotofácil. O projeto demonstra experiência com desenvolvimento backend, integração de sistemas e implantação em ambientes conteinerizados.

Quem sou?

Sou desenvolvedor web com formação em Sistemas de Informação, Ciências da Computação e pós-graduação em Desenvolvimento Web. Atualmente concentro meus estudos e projetos no desenvolvimento de aplicações modernas, buscando unir código limpo, interfaces intuitivas e soluções que realmente atendam às necessidades dos usuários.

Ao longo da minha trajetória profissional, construí uma carreira de 16 anos no setor bancário, experiência que desenvolveu habilidades como responsabilidade, organização, resolução de problemas e foco em resultados. Hoje aplico essa mesma disciplina no desenvolvimento de software, transformando ideias em aplicações funcionais e bem estruturadas.

Este portfólio reúne projetos desenvolvidos para colocar em prática diferentes tecnologias e desafios do desenvolvimento web. Estou sempre aprendendo, aprimorando minhas habilidades e acompanhando as melhores práticas do mercado para entregar soluções cada vez mais completas.

"Desenvolver software vai além de escrever código: é criar soluções que geram valor para as pessoas."
